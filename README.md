# VyuKarya

VyuKarya is a collaborative project and team management SaaS designed to help small teams organize projects, manage tasks, assign responsibilities, track progress, and collaborate from a centralized workspace.

## Project Status

🚧 In Development

The project is currently in the foundation phase.

## Planned Technology Stack

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS
* Redux Toolkit

### Backend

* Node.js
* Express.js
* TypeScript

### Database

* MongoDB
* Mongoose

### DevOps & Cloud

* Docker
* GitHub Actions
* AWS

## Core Features

* User authentication
* Workspace management
* Team member management
* Project management
* Task management
* Task comments
* Dashboard and project overview
* Role-based authorization

## Development Approach

VyuKarya is being developed using a build-to-learn approach. The project focuses not only on building features but also on learning modern software engineering practices such as TypeScript, testing, Git/GitHub workflows, Docker, CI/CD, and AWS.
